## Sophire the Chatbot
Welcome to our SDS Capstone Project. This repo contains the following document about Sophire:
- /quarto-manuscript/data contains all the SR Letters used to train Sophire
- /quarto-manuscript/question contains the expert and silly questions to measure the performance of Sophire
- /quarto-manuscript/index contains the code to generate our final report
- test_notebook_updatedd.py and test_notebook.ipynb contains the code to run Sophire. Run the python script on your local host to be able to access the sources on the Fed Website
- chroma_db: this folder contains the embeddings to avoid re-running the models and increase efficency
- word_count: the notebook to create the file /quarto-manuscript/word_counts.csv
